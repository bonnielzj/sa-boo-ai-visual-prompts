## SA&BOO Style Mixer

library, asset index, or separate visual-audit workflow merely to use this prompt

### Mixing method

For each requested style, rewrite these dimensions:

- Material
- Color
- Composition
- Lighting
- Texture
- Typography/text presence
- Detail density
- Commercial use case

### Controlled batch mode

When several variants must remain recognizably the same design:

1. Lock subject identity, geometry, product proportions, camera, crop, logo/text-safe zone, and one or two palette anchors.
2. Change only the selected style dimensions: material, texture, light, detail density, typography behavior, motion, or cultural mechanism.
3. For image editing, state the reference role and preserve/change contract for every input image.
4. Reject variants with subject drift, proportion changes, fake text, duplicated objects, inconsistent perspective, or brand-mark movement.

### Fast command pattern

When the user says “把{主题}做成不同风格口令”, produce 5-10 variants. If no number is given, produce 6:

1. Liquid Silver Luxury
2. Technical Blueprint
3. Victorian Ornamental
4. Minimal Editorial
5. Cyber Acid
6. Xiaohongshu Cover

### Avoid

Do not make all variants synonyms. Each must have a clearly different visual mechanism.

### Trend-aware style expansion

When the user asks for current/Canva-like/Adobe/Figma/social visual directions, use the parent Prompt Lab's trend references and remix the subject through trend mechanisms, not just named styles. Recommended current mechanisms include: Reality Warp, Texture Check, Opt-Out quiet editorial, Drama Club cinematic hook, Prompt Playground retro-tech UI, Notes App Chic, Zinegeist, 3D immersive web hero, and dark chrome retrofuture.

Each variant should state the changed mechanism: material, composition, light, texture, typography/text zone, detail density, and commercial use case.

Add these current production mechanisms when relevant:

- **Editable Layer Handoff**: create clean foreground/background/object separations and reserve a Canva/Figma assembly step instead of treating a flat raster as final.
- **Parallel Consistency Edit**: generate or edit several references in one batch while locking identity, camera, crop, and palette anchors.
- **Motion/Shader Material Study**: translate glass, chrome, liquid, grain, displacement, and light behavior into a still keyframe plus motion notes for Figma/WebGL/video handoff.
