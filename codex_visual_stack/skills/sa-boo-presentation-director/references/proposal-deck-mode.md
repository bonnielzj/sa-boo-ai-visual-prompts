# Proposal Deck Mode

Use this mode when the deck must persuade a client, recommend a design direction, or structure a commercial decision—not merely present information.

## Proposal contract

Define:

```text
Proposal type: first pitch / concept / layout comparison / FF&E / brand / final report
One-sentence thesis:
Client decision to unlock:
Confirmed evidence:
Design interpretation:
Unknowns and next proof:
Recommendation:
Implementation path:
```

For retail and branded-commercial work, inherit the approved milestone and evidence state from `sa-boo-retail-design-partner`; polished narrative must not approve an unsupported design stage.

## Narrative spine

Default sequence:

```text
project understanding
→ key relationship or demonstrated challenge
→ design thesis
→ evidence and strategy
→ options or system
→ recommendation
→ implementation, budget, timing, and next decision
```

For each slide define title, conclusion, evidence, visual form, speaker action, and the client decision it advances. Use decisive titles rather than topic labels.

## Scope adapters

### Interior concept

Brief → existing-condition diagnosis → thesis → spatial strategy → options → recommendation → materials/FF&E → budget/timeline → next decisions.

### Residential layout

Household/lifestyle → original-plan diagnosis → fixed constraints → precedents/pitfalls → options → scoring matrix → recommended plan → routes/storage/wet-area risk → implementation.

### Brand / VI

Diagnosis → audience/commercial goal → brand premise → visual thesis → fixed
identity and developable rules → real applications → governance → next approval.

For artists, distinguish the persistent personal identity, individual works, and
campaign/product worlds. Their relationships may be explained across pages instead
of through a forced shared motif or mixed-image spread. Preserve official marks
and each authorized work; do not infer official event use from proposal artwork.

### Soft furnishing / FF&E

Lifestyle and atmosphere → material/color palette → furniture/lighting/textile/art language → room-by-room plan → budget → procurement risk → installation sequence.

## Writing rules

- One main idea and one audience decision per slide.
- Explain choices through cause and effect.
- Make recommendations explicit on comparison pages.
- Separate confirmed evidence, design judgment, published/client claims, spatial proof, operating proof, and unknowns.
- Use poetic language only when function, light, material, circulation, budget, or brand value earns it.
- End with a concrete approval or next action.

Use the main `sa-boo-presentation-director` workflow for route selection, authoring, layout rhythm, and structural/visual QA. Use the current `Presentations` skill for editable PPTX production.
