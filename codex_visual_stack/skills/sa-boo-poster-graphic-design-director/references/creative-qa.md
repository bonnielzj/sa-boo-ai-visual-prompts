# Poster and KV Creative QA

Read this before presenting a candidate as the recommended craft direction and again
before release. Technical PASS never equals creative approval.

Use only the checks that can change this decision, and keep routine review silent.
Concept previews do not require composition alternatives, font boards, format
adaptations, editable sources, or a QA report. Those branches apply only when
the current question or requested deliverable needs them. Judge the whole work's
purpose and expression separately from locally correct contact or material cues.

## 1. Authority and evidence

- [ ] Selected brand and campaign authority is explicit.
- [ ] Logo/crest files are verified masters, not generated approximations.
- [ ] Actual reference inspection answers the relevant design questions; a clear
      supplied source can be sufficient, and reference quantity is not a quality gate.
- [ ] Each reference has attraction, effect, mechanism, do-not-copy, and original
      translation.
- [ ] Reference rights and production-asset rights are not conflated.

## 2. Dominant visual event

- [ ] The poster can be described as one visual action or spatial condition.
- [ ] One element or relationship clearly dominates at thumbnail scale.
- [ ] Structural field, supporting cues, and certification are subordinate.
- [ ] Removing decoration does not reveal an empty or generic layout.
- [ ] The event expresses the campaign idea, not merely “sports,” “youth,” or “energy.”

## 3. Composition

- [ ] If composition alternatives were needed or requested, they tested meaningful
      variables with concrete selection/rejection reasons. Otherwise judge the actual pilot.
- [ ] The poster has intentional pressure, silence, crop, and reading movement.
- [ ] It does not read as stacked presentation zones or a social template.
- [ ] Supporting elements do not form an even decorative border around the content.

## 4. Typography

- [ ] Typography has a deliberate voice, scale, rhythm and role; when it is the
      main image, its silhouette carries the idea. Supporting type may remain quiet.
- [ ] Chinese and English have explicit semantic and rhythmic roles.
- [ ] The actual copy works at viewing scale; when font choice was unresolved,
      a small relevant licensed set was compared. Reuse a fitting approved face.
- [ ] Chinese glyphs, punctuation, dates, numerals, and details remain correct and
      readable.
- [ ] No unverified font was downloaded, embedded, or redistributed.

## 5. Color, image, and material

- [ ] Field, counterforce, neutral, and optional signal have clear roles.
- [ ] Brand colors are not distributed evenly by default.
- [ ] Image treatment changes meaning, focus, rhythm, or atmosphere for a stated reason.
- [ ] Texture and artifacts have credible medium or narrative causes.
- [ ] Noise, distress, glow, halftone, and stars are not used as filler.
- [ ] The amount of treatment respects type and logo edge integrity.

## 6. Poster—not UI

- [ ] No card, pill, tab, button, dashboard, or interface hierarchy drives the layout.
- [ ] CTA or information is typographic and spatial, not styled as a clickable control.
- [ ] The logo is integrated into the field and never isolated in a patch or white box.
- [ ] Decorative badges are used only when they are conceptually and brand-authorized.

## 7. Communication

- [ ] The core message is understood within the intended dwell time.
- [ ] Mandatory copy, date, location, course, audience, or action is correct.
- [ ] There is enough contrast at real output size, not only at 100% canvas zoom.
- [ ] The emotional register matches the campaign's desired reaction.
- [ ] The result has a memorable project-specific feature rather than generic category
      styling.

## 8. Adaptation

Apply only to the requested set of formats.

- [ ] The campaign's invariant recognition is named.
- [ ] Each requested format is recomposed rather than proportionally scaled.
- [ ] Production, platform, and semantic safe zones are distinguished.
- [ ] Thumbnail/distance and crop-overlay proofs have been checked.
- [ ] Small formats remove unnecessary surface detail rather than shrinking everything.

## 9. Editable and export integrity

Apply only when an editable master or production release is requested. A raster
preview needs correct copy/identity and a usable actual image, not this package.

- [ ] Exact text, identity, details, rules, and masks remain editable.
- [ ] Generated/raster hero art is separate from live copy and verified identity.
- [ ] Fonts, assets, colors, approval status, and source paths are recorded.
- [ ] There are no missing fonts/assets, accidental overflow, hidden placeholders, or
      exporting guides.
- [ ] Rendered proof matches the editable master.

## 10. Approval status

Return one of:

- `CRAFT_STUDY` — mechanism or composition is still being tested;
- `STANDARD_PREVIEW_FOR_SELECTION` — clear proof, not yet user-selected;
- `SELECTED_PENDING_REFINEMENT` — direction selected, detail work remains;
- `CREATIVE_APPROVED_PENDING_PRODUCTION` — explicit approval recorded, production not complete;
- `TECHNICAL_PASS_PENDING_USER_APPROVAL` — file passes checks but creative approval is absent;
- `RELEASE_READY` — explicit creative approval plus editable/export QA.

Never infer approval from positive tone, file creation, Figma presence, or technical
validation.
