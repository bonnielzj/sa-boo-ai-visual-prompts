## Included refinements

Critique findings prioritize the current brief, visible evidence, impact, and
specific fixes. Numerical design conventions are contextual guidance. Real
strengths and the next useful change inform a concise review without a mandatory
checklist report.

[Font comparison](skills/sa-boo-poster-graphic-design-director/references/font-pairing-comparison.md)
uses project copy and the actual layout, Chinese/Latin glyph checks, role-based
font mapping, preserved originals, and inspected reflow. It is optional when font
choice is relevant; no fixed five-option sequence or specimen-label copy is
required.

## Scope and restoration

Copy the required skill folders to the host's skill directory after reviewing the
instructions and runtime requirements. Do not activate every companion by default.
Named Figma, image, document, research, or native-software companions are optional
host capabilities; this update does not bundle or configure them. In particular,
a historical Figma backup elsewhere in this repository is not proof of a current
connected or compatible Figma backend.

The helpers may require Python plus libraries such as Pillow or FontTools, or an
available PDF renderer/native design application. Inspect each helper's own
requirements before use. Font files, Adobe applications, account credentials, and
private project assets are not included. Structural validation and Python syntax
checks do not prove live font loading, visual quality, accessibility conformance,
or a successful native application export.

## Export boundaries and rights

These are public-storage copies of reusable methods. Local source skills remain
unchanged. Private reference images, image manifests, lyrics, private design links,
and client-specific project evidence are excluded or replaced with generic
teaching examples. Personal filesystem locations are replaced with portable
placeholders. Generic examples are not historical test results.

Existing skill license fields and source attribution are retained. Uploading a
backup does not grant a new redistribution license, rights to referenced fonts,
or rights to third-party artwork. Previously archived material outside this VI
update has not been re-audited or removed.
